# Customer Churn Analysis | Excel, SQL, Python & Power BI

## 📌 Project Overview
This end-to-end Customer Churn Analysis project explores customer behavior, churn patterns, revenue, and retention using Excel, SQL, Python, and Power BI. The goal is to transform raw customer data into meaningful business insights through data cleaning, exploratory analysis, querying, and interactive visualization.

## 🎯 Project Objectives
- Clean and prepare customer data for analysis.
- Analyze customer churn and retention patterns.
- Explore customer behavior and revenue trends.
- Identify churn patterns across contract types, internet services, and payment methods.
- Build an interactive dashboard to communicate key findings.

## 🛠️ Tools & Technologies
- **Microsoft Excel:** Data inspection, cleaning, formatting, and preliminary analysis.
- **SQL:** Data querying, filtering, aggregation, and customer analysis.
- **Python:** Data cleaning, exploratory data analysis (EDA), and analysis using Jupyter Notebook.
- **Power BI:** Interactive dashboard creation, DAX measures, KPIs, and visualizations.

## 🔄 Project Workflow
1. **Data Preparation — Excel:** Inspect and clean the raw customer dataset.
2. **Data Analysis — SQL:** Write queries to analyze churn, customer segments, and revenue.
3. **Exploratory Data Analysis — Python:** Explore distributions, trends, and relationships in the dataset.
4. **Dashboard Development — Power BI:** Create interactive visuals and calculate KPIs using DAX.
5. **Insights & Reporting:** Present findings through a consolidated dashboard.
